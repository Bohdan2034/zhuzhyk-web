# Шпаргалка викладача

- Якщо застрягли, повертайтесь до **RED** і **p95**. Це головна історія.
- Перехід «метрика → трейс → лог» артикулюйте як `route → span → trace_id`.
- Пояснюйте абревіатури (SDLC, SLI/SLO/SLA, MTTR, OTLP) мовою слухачів при першій появі.
- На кожному слайді повторюйте «Навіщо?» (економія часу/грошей/нервів).
- Уникайте: вибухової кардинальності в метриках, PII у логах, 100% трейсингу в проді, алертів без конкретного власника.
- Демонструйте pipeline: показуйте `otel-collector-config.yaml` й підкреслюйте `receivers → processors → exporters`.
- Продемонструйте readiness: підвищіть `READY_DELAY_MS`, перезапустіть лише `app`, покажіть `/healthz` (200) проти `/readyz` (503).
- Для кейсу «p95 ввечері» використайте `curl "http://localhost:3000/api/checkout?flow=slow-db"` + Grafana dashboard.
- Якщо потрібні артефакти для рунабука, зберіть: скрін RED, `trace_id`, інтервал часу, версію сервісу.
- Фіксуйте питання аудиторії — кілька з них перетворіть на домашку/продаж ідей менеджменту.
